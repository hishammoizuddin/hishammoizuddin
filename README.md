Software Engineer · Agentic AI and data driven full-stack systems

I build agentic systems that survive contact with production: LangGraph orchestration, MCP servers that turn legacy REST endpoints into agent-callable tools, and the observability layer that tells you which run broke and why. The other half is the stack underneath, Java, Spring Boot, and React, because agents are only as reliable as the systems they call.
